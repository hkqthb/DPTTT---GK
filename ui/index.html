So sánh hiệu năng Vectorized vs Naive Attention

Chạy thuật toán Attention ở hai phiên bản và so sánh thời gian thực thi (ms):

  • Vectorized (O(L^2) Matrix ops): Dùng NumPy viết tối ưu bằng phép nhân ma trận đa chiều, tính toán song song.
  • Naive (O(L^2) Loops): Dùng các vòng lặp for lồng nhau. Rất chậm khi chuỗi dài.
